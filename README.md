# Glaze

**Gaze-guided reading. No AI. No rewrite.**

The Wispr Flow of consumption.

AI made generating text 10× easier. Reading is still the bottleneck.

Glaze is a lightweight layer that tracks your gaze, slightly zooms the paragraph you’re on, and floats a clean guide line under the text — then shifts as your eyes move.

No rewriting. No tokens burned. Just better reading.
